# Public domain

## In short

No one holds copyright on the work any more, so anyone can use it freely. There is no license text because none is needed.

## You may

- Copy, share, modify and use the work for any purpose, including commercial use.
- Republish it, for example in this repository.

## You must

- Nothing is required by copyright law. Naming the artist and the source, as wallman does, is good practice.

## You cannot

- Claim you created the work.
- Assume that a faithful photograph or scan of an old artwork adds new rights: in many countries it does not, but the rules differ, so keep the source of the file in the entry.

## In this collection

A work is in the public domain when its copyright has expired (for most countries, a set number of years after the author's death) or when it was never protected: works by some governments, such as images published by NASA, are public domain by law. That is why such works are shareable. Committed to git: files in the public domain may be committed to the git repository. wallman allows `Add to git` for them, because no one holds rights that forbid republishing copies.
